# ProPay: Real-Time Banking Fraud & Cognitive Quishing Defense Agent
**Pirate Wires × pleasecallmechamp.com × Motion.dev Editorial Studio**

ProPay is an enterprise-grade AI risk infrastructure designed to detect emerging zero-day digital banking threats in real time—specifically **Physical QR Code Tampering (Quishing)** and **Unsolicited Smishing/Phishing Links**—using a dual-speed architecture powered by an on-premises **Ollama LLM cluster**.

---

### Quick Start (Zero Setup)
- **Instant Browser Demo:** Double-click `index.html` to open in Google Chrome or Microsoft Edge. All interactive features, live simulator presets, and telemetry streams work 100% offline.
- **Local Server (Python):** Run `python server.py` or double-click `run_propay.bat`. Opens at `http://localhost:5055`.

### Core Architecture & Design Crossover
1. **Pirate Wires × pleasecallmechamp.com Design**:
   - Towering condensed wordmark (`PROPAY`) with custom embedded shield badge inside the letter `P`.
   - Editorial lead story split layout with live Risk Radar HUD.
   - Date banner strip with 3-column newspaper cards.
   - Obsidian pitch-black canvas (`#070708`), hairline 1px architectural grids, subtle film-grain texture.
   - High-voltage Acid Volt (`#E8FF47`) and Signal Orange (`#FF5722`) focal accents.
2. **The 3 Threat Sectors**:
   - **Sector 1 (Edge Ingestion & Threat Parser):** Decodes QR URI payloads (`pa`, `pn`, `am`), unrolls shortened links (`bit.ly`), and strips Punycode character spoofs in $< 5\text{ms}$.
   - **Sector 2 (Ollama Cognitive Engine):** Private on-premise cluster (Llama 3 / Mistral) strictly scoped to semantic phishing text analysis, QR merchant-vs-payee mismatch heuristics, and forensic case dossiers. Never holds the sub-50ms wire clearance path.
   - **Sector 3 (Adaptive Mitigation & Interception):** Dynamic in-app warning overlays on customer mobile devices, automated payment freeze, and auto-generated FinCEN SAR filings.
3. **Interactive Live Threat Simulator**:
   - One-click presets for Clean Wires, Quishing Attacks, and Unsolicited Smishing Links with real-time execution trace telemetry.
4. **C4 Level 2 High-Level Architecture (HLD)**:
   - Built-in interactive modal breaking down the 6 enterprise tiers and the strict Ollama boundary matrix.
